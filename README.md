# 🎨 TerminalArte

Animações e visualizações artísticas no terminal — sorting algorithms, Matrix rain, Game of Life, fogo, pinball, campo estelar e cubo 3D.

## Tech Stack

- .NET 9 / Console App
- Arquitetura em camadas (Core + Console)

## Como Rodar

```bash
dotnet run --project src/TerminalArte.Console
```

## Artes Disponíveis

- 📊 Sorting Algorithms (Bubble, Selection, Insertion, Quick Sort)
- 🟩 Matrix Rain
- 🧬 Conway's Game of Life
- 🔥 Fire Effect
- 🎮 Pinball
- 🧊 Cubo 3D
- ⭐ Starfield

## Arquitetura

```
src/
├── TerminalArte.Core      ← Algoritmos e lógica das artes
└── TerminalArte.Console   ← UI e renderização no terminal
```
