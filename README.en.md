# 🎨 TerminalArte

Artistic animations and visualizations in the terminal — sorting algorithms, Matrix rain, Game of Life, fire, pinball, starfield and 3D cube.

## Tech Stack

- .NET 9 / Console App
- Layered architecture (Core + Console)

## How to Run

```bash
dotnet run --project src/TerminalArte.Console
```

## Available Art

- 📊 Sorting Algorithms (Bubble, Selection, Insertion, Quick Sort)
- 🟩 Matrix Rain
- 🧬 Conway's Game of Life
- 🔥 Fire Effect
- 🎮 Pinball
- 🧊 3D Cube
- ⭐ Starfield

## Architecture

```
src/
├── TerminalArte.Core      ← Art algorithms and logic
└── TerminalArte.Console   ← UI and terminal rendering
```
